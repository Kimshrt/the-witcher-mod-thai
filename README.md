 The Witcher 3: Wild Hunt — Thai Language Mod
 ปรับปรุงสำหรับเกมเวอร์ชัน 5.00b (อัปเดตปี 2026)

mod ภาษาไทย (แฟนเมด ไม่เป็นทางการ) ที่ปรับให้ใช้กับเกมเวอร์ชัน 5.00b ได้
โดยแปลงไฟล์ข้อความให้เป็นรูปแบบใหม่ของเกม และเติมข้อความใหม่ที่เกมเพิ่มมา


----------------------------------------------------------
 1) ไฟล์ที่ต้องมี
----------------------------------------------------------

ต้องมี 2 โฟลเดอร์ ใส่ในโฟลเดอร์ "mods" ของเกม:

  The Witcher 3\mods\modThaiLanguage     (ข้อความไทย)
  The Witcher 3\mods\modThaiFont         (ฟอนต์ไทย)

ภายใน modThaiLanguage\content\ ต้องมีครบ:

  tr.w3strings        ข้อความไทยทั้งหมด (ไฟล์ที่ปรับปรุงใหม่)
  en.w3strings        ไฟล์ว่าง (จำเป็น ห้ามลบ)
  blob0.bundle
  metadata.store
  scripts\game\gui\hud\modules\hudModuleDialog.ws
  scripts\game\gui\hud\modules\hudModuleSubtitles.ws

ภายใน modThaiFont\content\ ต้องมี:

  blob0.bundle
  metadata.store


----------------------------------------------------------
 2) วิธีติดตั้ง
----------------------------------------------------------

1. ปิดเกมให้หมดก่อน
2. คัดลอกโฟลเดอร์ modThaiLanguage และ modThaiFont ไปวางใน
   The Witcher 3\mods\   (ถ้าไม่มีโฟลเดอร์ mods ให้สร้างขึ้นมา)
   ถ้ามี mod ภาษาไทยเวอร์ชันเก่าอยู่แล้ว ให้ลบหรือย้ายของเก่าออกก่อน
3. เปิดเกม ไปที่ Options > Language
   เลือก Text language เป็น "Turkish"
   (mod นี้ทับภาษาตุรกี จึงต้องเลือกภาษานี้เพื่อให้ข้อความไทยขึ้น)
   ส่วน Speech language เลือกตามต้องการ (เช่น English)
4. ถ้ามี mod อื่นที่แก้ไฟล์ script ตัวเดียวกัน
   (hudModuleDialog.ws / hudModuleSubtitles.ws)
   ต้องรวมกันด้วย Script Merger


----------------------------------------------------------
 3) สิ่งที่ปรับปรุงในเวอร์ชันนี้
----------------------------------------------------------

- แปลงไฟล์ tr.w3strings จากรูปแบบเก่า (เวอร์ชัน 162, UTF-16)
  เป็นรูปแบบที่เกม 5.00b ใช้ (เวอร์ชัน 164, UTF-8)
  แก้ปัญหาตัวไทยกลายเป็นกล่องสี่เหลี่ยม/ตัวอักษรมั่ว
- เพิ่มข้อความใหม่ที่เกมอัปเดตเพิ่มมา 2,577 ข้อความ
  (เมนู mod.io, การตั้งค่า, ระบบสกิลใหม่, เควส/บทสนทนาใหม่, โหมดถ่ายภาพ,
  ส่วนควบคุมสำหรับ Nintendo Switch 2, credits ฯลฯ)
  ข้อความเหล่านี้แปลด้วย AI จากภาษาตุรกี แล้วตรวจแก้ด้วยมืออีกรอบ
  (ดูหัวข้อ 5)
- ข้อความไทยเดิมของ mod (ประมาณ 94,000 ข้อความ) ไม่ถูกแก้ไข
- ชื่อเฉพาะ ศัพท์เกม และรูปแบบ credits ใช้ตามแนวทางของ mod เดิม
  (ชื่อตัวละคร/สถานที่เป็นตัวละติน, credits เป็นภาษาอังกฤษ)


----------------------------------------------------------
 4) ข้อจำกัด / ข้อควรทราบ
----------------------------------------------------------

- ใช้กับเกมเวอร์ชัน 5.0 ขึ้นไปเท่านั้น
  ห้ามใช้ tr.w3strings นี้กับเกมเวอร์ชันเก่ากว่านั้น
  (รูปแบบไฟล์ไม่ตรงกัน)
- ห้ามนำไฟล์จาก mod เวอร์ชันเก่า (mod_thai_nextgen) มาผสมกับชุดนี้
- ข้อความใหม่ 2,577 ข้อความแปลจากภาษาตุรกี ไม่ใช่จากต้นฉบับอังกฤษ
  และยังไม่ได้ผ่านการตรวจโดยเจ้าของภาษาไทยทุกบรรทัด
  จึงอาจมีคำแปลที่ไม่เป๊ะ โดยเฉพาะสำนวน มุกตลก และคำหยาบ
- ส่วนที่ผู้ทำ mod เดิมเป็นคนแปล ไม่ได้ถูกแก้ไขหรือตรวจใหม่ในชุดนี้
- ยังไม่มีการรับรองว่าใช้งานร่วมกับ mod อื่นได้ทุกตัว


----------------------------------------------------------
 5) เครดิต
----------------------------------------------------------

ผลงานต้นฉบับ (ข้อความภาษาไทยกว่า 94,000 ข้อความ, ฟอนต์ไทย,
ระบบซับไตเติลมีสี):
  Thai Language Community Mod
  จากกลุ่มชุมชน The Witcher 3 Thailand
  https://www.nexusmods.com/witcher3/mods/8434
  ทุกความอุตสาหะในการแปลเกมทั้งเกมเป็นภาษาไทยเป็นของผู้ทำ mod เดิมและ
  ผู้ร่วมแปลทุกท่าน ชุดนี้เพียงปรับให้ใช้กับเกมเวอร์ชันใหม่

สคริปต์ซับไตเติล/บทสนทนา (hudModuleDialog.ws, hudModuleSubtitles.ws):
  มาจาก mod ภาษาไทยเดิม (มีคอมเมนต์ระบุผู้เขียนว่า "svvv" ในไฟล์)

ปรับปรุงสำหรับเกม 5.00b:
  - แปลงรูปแบบไฟล์ข้อความ (เวอร์ชัน 162 -> 164) และรวมข้อความ
  - แปลข้อความใหม่ 2,577 ข้อความ และตรวจแก้ด้วยมือ
  ทำโดยเจ้าของไฟล์ชุดนี้ ร่วมกับ Claude Code (Anthropic)
  โดยใช้โมเดลแปลภาษา Qwen3 ผ่าน API gateway ของเจ้าของชุดนี้
  (ใช้เป็นร่างแปลเบื้องต้น ก่อนตรวจแก้ด้วยมือ)

เครื่องมือที่ใช้:
  - w3strings encoder (Nexus Mods: witcher3/mods/1055)
    ใช้ถอดรหัสไฟล์ .w3strings รูปแบบเก่า
  - QuickBMS (ตรวจสอบไฟล์ .bundle)

The Witcher 3: Wild Hunt เป็นลิขสิทธิ์ของ CD PROJEKT S.A.
"THE WITCHER" เป็นเครื่องหมายการค้าของ CD PROJEKT S.A.
mod นี้เป็นงานแฟนเมดที่ไม่เป็นทางการ ไม่ได้เกี่ยวข้องกับหรือได้รับการ
รับรองจาก CD PROJEKT RED ไม่มีการแจกจ่ายไฟล์เกมต้นฉบับ


----------------------------------------------------------
 6) การแจกจ่ายต่อ
----------------------------------------------------------

- ก่อนแจกจ่ายต่อ โปรดให้เครดิตผู้ทำ mod เดิมตามหัวข้อ 5 ทุกครั้ง
- เนื่องจากงานหลักเป็นของ Thai Language Community Mod
  ควรตรวจเงื่อนไขการนำไปแจกต่อของ mod ต้นฉบับ (หน้า Nexus mod 8434)
  หรือขออนุญาตผู้ทำก่อนอัปโหลดที่อื่น
- ห้ามนำไปขาย


----------------------------------------------------------
 7) แจ้งปัญหา / การถอนการติดตั้ง
----------------------------------------------------------

ถอนการติดตั้ง: ลบโฟลเดอร์ modThaiLanguage และ modThaiFont
ออกจาก The Witcher 3\mods\ แล้วเปลี่ยน Text language กลับ

ถ้าพบข้อความแปลผิดหรือแปลกในข้อความใหม่ ให้จดหมายเลขหรือส่งภาพหน้าจอ
พร้อมบอกว่าอยู่ตรงไหนของเกม เพื่อนำไปแก้ไขในเวอร์ชันถัดไป
